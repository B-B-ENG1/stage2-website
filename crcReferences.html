Non-Functional Requirements

Requirement ID Description CRC Cards Involved Implementation
NFR_NAVIGATION Map easily traversed GameScreen, Player Optimize map size + move speed
NFR_MAP_LOAD Maps shall load without noticeable delay Main, GameScreen, RonCookeScreen, LangwithScreen, PiazzaScreen Preloading tiled maps and assets via LibGDX asset handling
NFR_PLAYER_RESPONSE Quick input response (<1ms) Player, GameScreen, RonCookeScreen, LangwithScreen, PiazzaScreen Direct input handling in game loop
NFR_GAMESPEED Gameplay speed shall remain consistent across devices GameScreen, Player, Goose, Lighting Delta-time based updates and frame-rate independent movement
NFR_GAME_END Game finishes within set time GameScreen, Main 5-minute timer
NFR_OS_VERSIONS The game shall run on Windows, macOS and Linux systems Main LibGDX cross-platform deployment and JVM compatibility
NFR_EASE Learnable within ~2 minutes; playable without frustration GameScreen, MainMenuScreen, InstructionsScreen Instructions and simple controls as well as prompts
